Luciano Metronome Guide

The Luciano Metronome is a free online tool with the following features:

  • Realistic look: faithfully reproduces the aesthetics of a classic mechanical metronome.
  • Flexible settings: you can adjust the tempo (BPM), the number of beats per measure, and other options.
  • Free and no registration: works directly in the browser, no installation needed.

BPM Settings

The set BPM value is displayed digitally on the metronome. Note that if the metronome is running, any setting changes will be activated at the beginning of the next measure.

There are various ways to change the BPM value:

  • You can adjust it by dragging the slider on the metronome.
  • You can increase/decrease by 1 or 5 units by clicking the buttons next to the BPM indicator.
  • You can increase/decrease using the UP / DOWN arrow keys on the keyboard.

Start / Stop

There are also several possibilities for starting/stopping:

  • Use the START/STOP button.
  • Use the spacebar on the keyboard.
  • Activate "Clap Start" mode. In this way, the metronome waits to receive a loud signal from the microphone, such as a hand clap. It must then be stopped using one of the other methods.

Time Signature

In the large central panel, you can select the time signature for the performance. The most common combinations are represented. Clicking on "More Options" reveals some more sophisticated ones.

In the upper panel, two timeline bands are graphically represented:

  • The upper one represents the main subdivisions (e.g., quarter notes).
  • The lower one represents the secondary subdivisions (e.g., eighth notes).

When the metronome is running, a cursor will scroll horizontally.

Next to each band, there is a speaker symbol. Clicking on it allows you to enable or disable the playback of the corresponding beats.

Additionally:

  • Next to the upper band, a clickable rectangle is displayed. When it is white, a special sound is played at the beginning of the measure.
  • The clickable rectangle next to the lower band, however, activates a special sound on every main beat when it is red.

Other Features

  • VOLUME: adjusts the playback volume.
  • ONE TWO THREE FOUR: adds vocal counting to the beats.
  • SWING: Adjusts the rhythmic "groove" by shifting the off-beat notes forward in time.
    • 0%: "Straight" rhythm, notes are evenly spaced.
    • ~33%: "Shuffle" or "Triplet" rhythm (typical of Blues/Jazz), with a bouncing feel.
    • Higher values accentuate the effect until the note overlaps with the next beat.

    Note: to hear the swing effect, the secondary subdivisions listening must be activated (the speaker icon on the second time band)
  • INTRO: If selected, upon starting, it plays one measure with beats, then one with "one two three four", and then proceeds normally.
  • CLAP START: to start playback via a hand clap (see above).
